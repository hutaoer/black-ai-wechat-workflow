## 技术探测：B站视频内容获取能力
- 结论：**读不到视频正文内容**（无法"看/听"）。未登录状态下可拿到的只有：标题、UP主、时长、播放/点赞/评论数、弹幕 XML、评论区文字。
- 可用接口（免登录，需带 UA + Referer: https://www.bilibili.com/video/<BV>）：
  - `api.bilibili.com/x/web-interface/view?bvid=` → 元信息 + cid
  - `api.bilibili.com/x/v1/dm/list.so?oid=<cid>` 或 `comment.bilibili.com/<cid>.xml` → 弹幕
  - `api.bilibili.com/x/v2/reply?type=1&oid=<aid>&sort=0|2` → 评论
  - `api.bilibili.com/x/player/playurl?...&fnval=16` → dash 音视频流直链（可下 m4s 音轨）
- 拿不到的：字幕（该视频 subtitle.list 为空）、B站官方 AI 总结（`/x/web-interface/view/conclusion/get` 需 wbi 签名 + 登录，返回 -101 账号未登录）。
- 本机：无 ffmpeg；Read 工具不支持音频。若要真正转录视频音轨 → 需本地装 ASR（faster-whisper/mlx-whisper + HF 镜像下模型）。
