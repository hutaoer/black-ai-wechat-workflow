# 余额宝跌到0.83%，我把闲钱挪到了这三个地方

早上打开支付宝看了一眼余额宝，七日年化0.83%，一万块一天两毛三。

记得余额宝刚出来那几年，年化冲到过6%。放一万块进去，一天一块多，比银行活期强太多。那时候我把工资卡里的钱全转进去，花的时候直接用，还能生利息，美滋滋。

后来收益一路往下掉。2020年跌破2%，2022年跌破1.5%，今年5月直接破了1%。现在0.83%，一万块一年才八十多块，连顿像样的饭都不够。

整个货币基金行业都在跌，近三成货基收益率已经跌破1%。央行维持宽松货币政策，市场上钱多了，借钱的成本就低，货基投的那些短期票据自然给不出高利息。

我也懒得折腾。日常要用的钱，分散放在三个地方。

招行的朝朝宝，七日年化1.06%，上限10万。好处是不用手动赎回，转账还款支付直接扣，跟活期一样用。工资到账我就转进去，比放活期强。

网商银行的余利宝，年化大概1.4%，比朝朝宝高一点。主要用来收收款和短期周转，随用随取。

且慢的盈米宝，七日年化1.48%，是这几个里最高的。且慢是基金投顾平台，活钱管理的钱可以随时取，放应急备用金很合适。

三个加起来，比余额宝多不了几倍，但胜在方便。日常开销的钱放朝朝宝，备用金放且慢，偶尔周转用余利宝。钱不多，每一分都尽量让它多挣两毛。

也不是没考虑过收益更高的产品。银行理财有2%到3%的，债券基金偶尔能到4%，但都有锁定期或者波动，不像货基随取随用。家里有老人孩子，钱得留一部分能随时拿出来的，不能全锁死。

我的想法很简单。随时要用的钱，找个比活期强的地方放着就行，别指望它发财。短期内不用的钱，再考虑银行理财或者短债基金。图个心里踏实。

理财这东西，适合自己的最重要。你呢，闲钱都放哪儿了？
