# 公众号AI文章工作流 · 使用手册

> 本手册既是**用户上手指南**，也是**AI开工前的必读说明**。
> 新会话（含每日定时任务）请先读本文件，再按需读取 `STYLE_GUIDE.md`、`WORKFLOW.md`、`TOPICS.md`。

---

## 一句话了解本项目

用AI复刻"我"的公众号写作风格，每天产出社会民生类文章：**1000字以内、观点犀利、有理有据、无AI味**。AI只负责到草稿，发布永远由作者本人手动完成。

## 文件地图

| 文件 | 作用 | 谁读 |
|------|------|------|
| `README.md`（本文件） | 上手手册 + AI开工须知 | 人和AI |
| `STYLE_GUIDE.md` | 风格指南：作者画像、写法规范、禁用清单、自检清单 | AI必读 |
| `WORKFLOW.md` | 三种模式的完整流程定义 | AI必读 |
| `TOPICS.md` | 选题池：平时攒的题目 | 人和AI共维护 |
| `posts/` | 历史文章 + 新稿，每篇一个目录（正文 `index.md`） | 存档 |

## 三种模式怎么选

```
有热点可蹭、想要流量        →  模式A（每日定时自动触发）
自己有想写的题、不追时效     →  模式B（随时发起，AI帮你补素材）
连结构都想好了、只要AI填肉   →  模式C（给题目+大纲，AI照骨架成稿）
```

## 模式A：热点模式（每天自动）

**触发方式**：无需任何操作。每天早上9:00，定时任务"公众号每日选题推送"自动运行，把3个候选选题送到你面前。

**每天的流程**：

```
9:00  AI自动抓取当日新闻热点，筛出民生类，按权重打分
 ↓    推送3个候选选题（附：一句话概述 + 切入角度 + 数据锚点 + 推荐排序）
 ↓    【你拍板】回复编号，如"选1"；或都不满意，说想要的方向
 ↓    AI成稿：按风格指南写作 → 跑自检清单 → 存 posts/ 
 ↓    交付：草稿 + "本稿的三个关键判断"
 ↓    【你修改】改完手动发布到公众号
```

**你需要做的只有两件事**：圈选题、改稿发布。

**选题打分权重**（AI按此排序）：作者经历可关联 +2 / 能算成一笔账 +2 / 有逆主流判断空间 +2 / 当日热度 +1。

**选题红线**：纯娱乐八卦、刑事案件细节消费、无法核实的传言、敏感制度议题——不推。

## 模式B：自命题模式（随时发起）

**触发方式**：直接把题目丢给AI，一句话就够。例如：

- `模式B，题目："2030年社保要交满20年，有什么影响"`
- `我想写写我爸妈的养老金`
- `帮我写篇关于兴趣班烧钱的`

**流程**：

```
【你给题】一句话题目或模糊方向均可
 ↓
【AI补料】联网搜索新闻由头、数据、政策条文 → 汇总"素材包"给你过目
          （数据须真实可查；查不到的标注"未核实"，禁止编造）
 ↓
【你确认素材】补充/剔除素材，指定想用的个人经历，或直接说"出稿"
 ↓
【AI成稿】同模式A：风格指南 → 自检清单 → 存 posts/ → 交付
```

**适合场景**：个人经历类（卖房、裁员、踩坑）、常青话题（不依赖当天新闻）、系列文章。

**给AI的提示**：用户给的题目若含事实性误读（如把渐进政策说成一刀切），素材包阶段要主动纠偏，这往往就是文章最好的钩子。

## 模式C：题目+大纲模式（随时发起）

**触发方式**：把题目和大纲一起给AI。大纲粗细皆可——细到每段写什么，粗到"三段式：现象-算账-建议"。例如：

```
模式C。
题目：《兴趣班，一个烧钱的无底洞》
大纲：
1. 开头：大宝开学报了3个班的账单
2. 中间：算一笔兴趣班的总账（一年多少钱，学到大学是什么量级）
3. 家长的心理：为什么明知烧钱还停不下来
4. 结尾：我的止损办法
```

**流程**：

```
【你给题+大纲】粗纲细纲均可
 ↓
【AI核料】快速核实大纲里的事实和数据，缺来源的补上
          ├─ 大纲没硬伤 → 直接成稿
          └─ 大纲有事实错误 → 先反馈问题，你确认后再动笔
 ↓
【AI成稿】严格按你的大纲结构写 → 风格润色 → 自检清单 → 存 posts/ → 交付
 ↓
【你修改】同模式A/B
```

**关键约定**：
- **大纲是结构的最高权威**——AI不擅自增删段落、颠倒结构；结构建议（如果有）只附在交付说明里，成稿仍按你的大纲
- AI只做三件事：核实事实补来源、用你的风格填肉、跑自检清单
- 大纲里没写的部分（标题、开头钩子、结尾互动）由AI按风格指南补齐

## 产出规范（三种模式通用）

1. **字数**：1000字以内，硬上限
2. **存放**：`posts/YYYYMMDD-标题/index.md`，目录名即标题
3. **必附**：
   - 文末数据来源（政策文件名/文号、官方发布）
   - 交付时附"本稿的三个关键判断"，方便作者快速评估
4. **成稿红线**：批现象不碰制度；犀利但落点建设性；涉亡故事件只哀悼不消费
5. **风格自检**：逐条对照 `STYLE_GUIDE.md` 第九节，任何一条不过即返工，不出手

## 终稿回存与风格迭代

你改完的终稿存回 `posts/` 对应目录后，告诉AI一声，它会：

1. diff 对照初稿与终稿，分析你的改动
2. 你**删掉的**写法 → 进风格指南"禁用"清单
3. 你**保留/新增的**写法 → 进"要用"清单
4. 风格指南持续迭代，越写越像你

## 常见问题

**Q：早上9点没看到推送？**
可能是当日热点不足或全不达标。主动问一句"今天有什么选题"即可手动触发模式A。

**Q：模式A推的选题都不想写？**
直接说要什么方向，AI重新筛；或者切模式B/C自己出题。题目也可以先记进 `TOPICS.md` 选题池攒着。

**Q：想调整推送时间/尺度？**
随时告诉AI，定时任务和风格指南的红线都可修改。

**Q：AI写的数字敢用吗？**
成稿所有数据必须带来源；没有来源的数字要么删掉要么标"未核实"。作者改稿时对数字多留个心眼，最终以官方原文为准。
